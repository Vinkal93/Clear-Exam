# ADR-001: Monorepo Structure, Backend Architecture, and Server-Authoritative Timer

## Context
ClearExam requires an Android native student app, a responsive web super-admin portal, and a shared API. We must ensure:
1. Tight contract alignment between frontend, backend, and admin.
2. Complete cheating resistance (no client-side clock tampering or leaked answer keys).
3. Independent student access without requiring institute membership.
4. Fast local development without cloud dependencies.

## Decisions

### 1. Unified Monorepo with npm Workspaces
We adopt an npm workspace monorepo layout:
- `apps/android`: Kotlin Android App
- `apps/admin-web`: Next.js 15 Web Portal
- `services/api`: Node.js Express REST API
- `packages/contracts`: Shared TypeScript schemas and DTOs
- `infra/firebase`: Firebase configuration and emulator seeds
- `docs/`: Centralized specifications and trackers

**Rationale**: Shared data models and API contracts prevent schema drift.

### 2. Single Database & Node.js Cloud Run Monolith
We reject premature microservices and multiple disparate databases. Firestore is the single authoritative store, managed via the Node.js API with Firebase Admin SDK.
**Rationale**: Eliminates synchronization lag, distributed transaction failures, and infrastructure sprawl.

### 3. Server-Authoritative Timing & Grading
Test attempts are initialized with server-assigned timestamps (`serverStartedAt`, `serverExpiresAt`). The test timer in the Android app acts as a local countdown mirror; grading and finalization depend exclusively on the backend timestamp.
**Rationale**: Prevents clock manipulation on user devices and guarantees fair test execution.

### 4. Zero Answer Key Disclosure in Test Payloads
Questions during active test attempts contain only options and question stems. The answer keys reside in private Firestore collections accessible strictly to the backend engine during grading.
**Rationale**: Precludes client inspection (via Charles/Proxyman or memory dumping) from extracting solutions during a live test.

## Status
Accepted and frozen.
